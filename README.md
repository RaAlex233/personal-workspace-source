# 个人工作台

React + TypeScript + Vite 构建的个人工作空间。底部 Dock 提供主页、视图、专注、Agent、我的五个入口；主页与详细页面共用任务、视图选择和番茄钟状态。

界面采用 WinUI / Fluent 风格：微软雅黑、中性灰背景、蓝色强调色、14–15px 正文和至少 12px 的辅助文字。底部 Dock 使用半透明 Acrylic 风格毛玻璃，浅色与深色主题保持一致的文字层级。字体优先使用设备已安装的微软雅黑；不支持毛玻璃或启用减少透明效果时使用实色底板。

## 运行与验证

需要 Node.js 20.19+（或 22.12+）。在项目目录执行：

```bash
npm ci
npm run dev
```

默认地址为 `http://127.0.0.1:5173`。生产构建使用 `npm run build`，核心数据和计时回归检查使用 `npm test`。使用 npm 与现有 `package-lock.json`，避免混用包管理器。

## 页面与功能

- **主页**：任务列表、番茄钟、月／周时间视图、可横向滚动的时间树。
- **视图**：完整日历、任务列表和时间树。选项栏位于下方；主页中点击展开会进入对应详细视图。
- **专注**：番茄钟、任务关联、暂停／继续、短休息与长休息、专注记录和过去七天统计。
- **Agent**：预留入口，本次不实现自动化能力。
- **我的**：专注与外观设置、账号登录界面、数据备份与恢复。账号登录暂未接入后端，填写表单不会产生真实登录或发送账号信息。

任务支持 Deadline、开始日期、长期／短期／紧急程度、自定义分类标签、备注以及 0–100% 的进度。添加标签时按 Enter 或点击加号，可复用已有标签。列表支持状态、紧急程度、标签、关键词筛选；详细列表支持排序。

## 时间视图与时间树

月视图用圆点标记任务与日程，周视图显示简短标题；点击日期查看当天安排。任务按开始到截止日期的区间显示，跨天日程会在覆盖的各天显示。

时间树按任务开始到截止日期绘制横向条带，填充表示手动维护的完成进度，不根据时间经过或专注时长自动推断。任务达到 100% 会标记完成，重新打开任务会重置为 0%。未设置截止日期的旧任务显示为持续中。拖动空白区域、使用横向滚动条或触屏滑动，可查看条带；下方按钮可调整日期窗口，超出窗口的任务提供跳转入口。点击任务名称或条带可编辑进度。

## 番茄钟

默认专注 25 分钟、短休息 5 分钟、长休息 15 分钟，每完成四轮专注进入长休息。时长、长休息间隔、结束提示音及自动开始休息可以在“我的”中设置。新设置从下一轮生效。

番茄钟以绝对结束时间计时，切换页面、浏览器后台及刷新不会重置。状态保存在此浏览器；关闭页面后仍按时间经过计算，重新打开时恢复或结算过期的计时。暂停期间不计入专注时间。自动休息在应用观察到专注结束时开始，下一轮专注仍需手动启动。

可以关联任务或自由专注。完成一轮后自动保留记录；提前结束并重置也会保留实际投入的秒数。完成番茄钟不会自动完成任务。删除任务会保留其专注时长，转为未关联记录。

## 数据与兼容性

工作台数据保存在当前浏览器的 IndexedDB；番茄钟进行中的状态保存在 localStorage。当前没有云端同步，账号页面仅提供界面。

“我的 → 数据管理”支持 JSON 导出与导入。合并模式按记录 ID 更新，以导入记录为准并保留当前设置；替换模式覆盖全部记录与设置，并要求确认。导出备份包含任务、日程、已保存的专注记录与设置，不包含正在运行的番茄钟状态。

旧版 `schemaVersion: 1` 数据与备份会自动迁移为版本 2：原任务与记录 ID 保留，旧分类转换为标签，优先级和分类转换为紧急程度，已完成任务设为 100%。保存错误会在页面顶部提示，可重试或导出当前记录。

更换设备或清除浏览器数据前，请先导出备份。当前为单浏览器的个人工作空间。

## 代码结构

- `src/Workspace.tsx`：页面入口、底部 Dock、主页与详细页的共享状态。
- `src/TaskPanel.tsx`、`CalendarPanel.tsx`、`TimeTree.tsx`：任务、日期安排与进度视图。
- `src/usePomodoro.ts`、`FocusPanel.tsx`：番茄钟状态与专注记录。
- `src/Profile.tsx`：设置、登录界面与数据管理。
- `src/data.ts`、`useWorkspace.ts`：数据格式、兼容迁移、本地存储与业务操作。
- `scripts/check-core.mjs`：迁移、导入校验、合并、任务日期区间和计时恢复的回归检查。
